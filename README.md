# Ereen Tolgoi corporate website

A responsive trilingual static website starter for Ereen Tolgoi.

## Languages
- Mongolian (default)
- English
- Simplified Chinese

## Files
- `index.html` — page structure and content
- `styles.css` — layout, responsive styling and theme variables
- `script.js` — language switching and mobile navigation

## Important before publishing
This is a first visual/content draft. Please confirm and replace:
1. Official company name in each language and legal entity name.
2. Official brand colors and logo.
3. Company profile and approved descriptions of operations/projects.
4. Official email, phone number, office address and social links.
5. News and project information.

The current contact details are intentionally placeholders. No contact form is connected to a backend.

## Brand colors
The current stylesheet uses a temporary neutral palette. Replace the CSS custom properties at the top of `styles.css` with the company's official brand colors when available.

## Deploy
Upload the contents of this folder to the GitHub repository, then configure iTools to pull from:
`https://github.com/Ereentolgoi/ereentolgoi-website`

The hosting document root should point to the folder containing `index.html` (currently configured as `httpdocs` in iTools).
